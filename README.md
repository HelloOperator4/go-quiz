# Go Quiz
Персональный PWA-тренажёр Go с 100 вопросами по 10 темам изученного курса (до задачи 270).

## Функции
- Тест из 10 случайно выбранных вопросов; отдельные темы или все темы.
- Теория и анализ Go-кода, четыре варианта, один правильный.
- Мгновенная проверка: «✓ Верно!» или «✕ Ошибка!» и объяснение.
- Автоматическая светлая/тёмная тема; история и продолжение попытки хранятся локально.
- После первоначальной загрузки офлайн-режим благодаря service worker.

## Публикация
В репозитории GitHub откройте Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
После публикации адрес будет https://HelloOperator4.github.io/go-quiz/

## Установка на iPhone
Откройте опубликованную ссылку в Safari → Поделиться → На экран «Домой» → Добавить.
После установки откройте приложение онлайн один раз для первоначального кеширования.

## Расширение
Вопросы находятся в data/questions.json. При публикации новой версии обновляйте CACHE_VERSION в sw.js, чтобы устройство обновило офлайн-файлы.
Репозиторий публичный. История ответов хранится только на устройстве пользователя.

## Локальная проверка
Для автономного запуска на компьютере можно использовать preview.html.
