# Go Quiz v1.1

Личный PWA-тренажёр Go, доступный по адресу https://hellooperator4.github.io/go-quiz/.

- 300 заданий по темам до задачи 270 включительно (200 новых и 100 из v1.0).
- 10 больших разделов, 30 подтем; по 30 заданий на раздел и 10 на подтему.
- На каждую попытку 10 вопросов с мгновенной проверкой и объяснением.
- Очередь по каждому разделу: сначала ещё не встречавшиеся задания, после исчерпания — новый цикл.
- В каждой подтеме всего 10 вопросов, поэтому повторный тест по ней повторяет набор; тест по всему разделу предоставляет больше разнообразия.
- Все результаты и незавершённая попытка остаются в локальном хранилище устройства. Старые результаты v1.0 сохраняются.
- PWA и офлайн-работа на iPhone. Не требуется сервер или App Store.

## Обновление на iPhone

Подключитесь к интернету и откройте приложение. При обновлении версии кеша (sw.js) новая версия будет подготовлена и станет доступной после повторного открытия приложения. Если не обновилось, закройте и повторно откройте веб-приложение с подключённым интернетом.

## Вопросы

База расположена в `data/questions.json`; каждый вопрос имеет поля `id`, `topic`, `subtopic`, `kind`, `question`, `code`, `options`, `answer`, `explanation`. Все `id` из v1.0 сохранены. Для расширения добавляйте вопросы, не меняя существующие идентификаторы, и поднимайте версию кеша в `sw.js`.

## Локальный запуск

Откройте `preview.html` для автономной проверки на компьютере либо запустите статический сервер в каталоге проекта (например, `python -m http.server 8000`).
